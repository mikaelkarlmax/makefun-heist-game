# The Meridian Job

A top-down stealth heist game. Three jobs, one night, one crew: you. Sneak the
Gallery, crack the Vault, lift the Penthouse crown — read the patrols, time the
camera sweeps, spend your tools wisely, and walk out with the loot.

- **3 levels** — The Gallery (3 guards, 2 cameras), The Vault (5 guards, 3 cameras),
  The Penthouse (7 guards, 4 cameras). $30,700 of loot on the floors.
- **Vision cones raycast against walls and cover** — guards patrol beats, get
  suspicious, then chase. Cameras sweep arcs and feed the alarm fast.
- **Alarm meter 0–100** — climbs while you're seen, falls while you're hidden.
  At 100% you get a short grace window to break line of sight before the bust.
- **Tools at a cost** — coins to lure guards (Q), EMP to kill cameras for 6s (F),
  smoke to vanish for 4s (Space). Safes need a 3-second lockpick hold (E).
- **HUD + minimap** — alarm bar, loot total, tool counts, timer, and a corner
  map showing walls, cones, loot, exit and you.
- **Ratings S/A/B/C** per job, by time, peak alarm and loot taken.

## Controls

| Key | Action |
| --- | --- |
| WASD / arrows | Move |
| Shift | Sneak (slow, harder to spot) |
| E (hold) | Grab loot / lockpick a safe |
| Q | Toss a coin to lure guards |
| F | EMP — cameras dark for 6s |
| Space | Smoke cloud — invisible inside for 4s |
| Click | Move to that spot |
| P / Esc | Pause |

## Play

Serve `game/` with any static server and open `game/index.html` in desktop
Chrome. Everything is offline: canvas art, synthesised WebAudio sound, no
network requests, no outside assets.
